# SJC

Sarah Joe conversational prototype.

## Stack

- React 19 + TanStack Start
- Vite + Tailwind CSS
- Zustand for local conversation persistence
- xAI streaming chat endpoint

## Configuration

Set `XAI_API_KEY` in the deployment environment. The key is used only server-side by `/api/chat`.

## Identity

The app is a fictionalized AI conversational portrayal inspired by publicly documented material. It does not claim to be Sarah Joe Chamoun / Mia Khalifa and does not fabricate private facts or real-world actions.

## Development

```bash
npm install
npm run dev
```

The development server uses port 8080.
